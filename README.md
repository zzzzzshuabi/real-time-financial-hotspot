# 实时金融数据热点监控系统

> Real-Time Financial Hotspot Monitor —— 面向股票 / 期货 / 加密货币市场的实时数据采集与热点识别设计知识库。

## 这是什么

本仓库是"实时金融数据热点监控系统"的设计知识库，覆盖从 **多源数据接入 → 实时流处理 → 热点识别 → 存储 → 告警推送** 的完整链路。目标是在市场异动发生后的**秒级~分钟级**内，把"哪只票、哪个板块、哪条新闻正在发酵、资金在往哪里涌"推送到你面前。

                                                                                                                            ## 核心能力
                                                                                                                            
                                                                                                                            - **多市场覆盖**：A股 / 港股 / 美股 / 期货 / 加密货币
                                                                                                                            - **多信号融合**：量价异动 + 资金流 + 新闻舆情 + 社媒讨论 + 公告
                                                                                                                            - **秒级延迟**：行情 WS 直连，快讯 30s 内进入计算
                                                                                                                            - **热点打分**：综合热度分（0~100），按股票 / 板块 / 话题聚合
                                                                                                                            - **可观测**：监控每个采集源延迟、丢数、错误率

                                                                                                                            ## 技术栈（推荐）
                                                                                                                            
                                                                                                                            - **语言**：Python（采集 / NLP，生态全）+ Go（高并发网关，可选）
                                                                                                                            - **消息队列**：Kafka 或 Redis Stream（MVP 用 Redis Stream 足够）
                                                                                                                            - **流计算**：MVP 用 Python asyncio worker；上规模用 Flink
                                                                                                                            - **时序库**：TDengine（A 股 tick 场景性价比高）或 InfluxDB
                                                                                                                            - **关系库**：PostgreSQL
                                                                                                                            - **搜索**：Elasticsearch / OpenSearch
                                                                                                                            - **实时榜**：Redis Sorted Set
                                                                                                                            - **前端**：React + ECharts（实时热力图 / 榜单）
