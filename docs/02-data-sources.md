## 6. 接入注意事项

- 免费源必须带 UA、限速、缓存，不要高频打
- 商用数据走官方 API，不要爬
- 行情 WS 断线自动重连，带指数补偿
- 新闻/公告注意版权，只存元数据和摘要
- 所有源配置化，新增源只改配置
