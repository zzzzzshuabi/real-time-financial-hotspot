# 04 · 热点识别算法（核心）

## 1. 总体思路

四路信号并行计算，每路输出 0~100 的归一化分，再加权融合成最终 `hot_score`。

```
量价异动 ─┐
资金流   ─┤
舆情热度 ─┼─► 加权融合 ─► hot_score(0~100) ─► 阈值告警
事件催化 ─┘
```

## 2. 四路信号定义

### 2.1 量价异动（权重 30%）

实时计算每个 symbol：
- **涨跌幅突变**：1 分钟内涨跌幅超过历史同时段均值 + 2σ
- **量比突增**：当前分钟成交量 / 过去 5 日同一分钟均量 > 3
- **突破信号**：价格突破近 20 日新高/新低
- **涨停/跌停**：直接满分
- **振幅放大**：分钟振幅 > 近 20 日均值 2 倍

输出：`price_anomaly ∈ [0, 100]`

### 2.2 资金流（权重 25%）

- 主力净流入（大单买入-大单卖出）分钟级聚合
- 北向资金净买入占该 symbol 成交比例
- 龙虎榜上榜（日级，收盘后计入次日早盘热度）
- 融资余额变化率

输出：`money_flow ∈ [0, 100]`

### 2.3 舆情热度（权重 25%）

- **讨论量增速**：过去 5 分钟讨论数 / 过去 1 小时均值，>3 倍加分
- **情感极性**：用预训练中文情感模型（如 FinBERT-Chinese）打分，正向/负向极端值加分
- **KOL 加权**：粉丝数 >10 万的账号发言权重 ×3
- **传播速度**：转发/评论增速

输出：`sentiment_growth ∈ [0, 100]`

### 2.4 事件催化（权重 20%）

- **关键词命中**：快讯/公告中命中预设关键词库（合同中标、业绩预告、政策文件、并购重组）
- **重大公告类型**：业绩预增 >50%、回购、增持、重大合同
- **政策文件**：国务院/部委发文涉及相关板块
- **同行业联动**：同板块多只股票同时异动

输出：`event_impact ∈ [0, 100]`

## 3. 融合打分公式

```
hot_score = 0.30 * price_anomaly
          + 0.25 * money_flow
                    + 0.25 * sentiment_growth
                              + 0.20 * event_impact
                              ```

                              - 每路信号先做 z-score 归一化，再 clip 到 [0, 100]
                              - 三个维度分别聚合：
                                - **个股级**：按 symbol
                                  - **板块级**：成分股 hot_score 加权平均
                                    - **话题级**：按聚类话题聚合

                                    ## 4. 告警阈值

                                    | 等级 | hot_score | 动作 |
                                    |---|---|---|
                                    > 70 | 高热度 | 立即推送企微/钉钉
                                    > 50 | 中热度 | 写入实时榜单，前端高亮
                                    > 30 | 观察 | 仅记录，不推送

                                    避免轰炸：同一 symbol 30 分钟内只推一次，热度下降 20 分以上才允许再次推送。

                                    ## 5. 话题聚类（进阶）

                                    - 快讯/社媒文本 → 中文分词（jieba）→ embedding（bge-small-zh）
                                    - 用 BERTopic / 增量 KMeans 实时聚类
                                    - 识别"AI 算力"、"创新药"、"固态电池"等概念的热度迁移
                                    - 输出：话题词云 + 成分股列表 + 热度趋势线

                                    ## 6. 冷启动与校准

                                    - 所有权重初始值写在配置里，上线后按实际推送效果（点击率、后续涨幅）回测调参
                                    - 每周回看 Top 100 热点，统计 T+1/T+5 的涨跌幅，计算命中率
                                    - 命中率 < 30% 的信号权重自动下调
